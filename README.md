# 📊 MarkX Result Analysis Tool

A modern, full-stack web application designed for **RTU Examination Result Analysis**. Built using **Flask**, **React**, and **MongoDB**, this tool provides a seamless, data-driven platform for students to access and analyze their examination results with powerful visual insights and downloadable reports.

> 🎯 Project Duration: **May 2023 – Present**

## 🧰 Tech Stack

| Layer      | Technology            |
|------------|------------------------|
| Frontend   | React.js, Tailwind CSS |
| Backend    | Flask (Python)         |
| Database   | MongoDB                |
| APIs       | RESTful (Flask-based)  |
| Other      | PDFKit, Axios, GitHub Pages / Render |

---

## ✨ Key Features

- **🎓 Student Portal**: Secure login, view results, subject-wise breakdown
- **📄 PDF Reports**: Download performance analytics as professional PDFs
- **📊 Visual Charts**: Semester and subject comparisons with dynamic graphs
- **🧾 Class Avg. Analysis**: Compare your scores with class performance
- **🔐 Secure & Scalable**: Flask backend + MongoDB = fast and secure

---

## 💡 Technical Highlights

- 🔌 **RESTful Flask API** for all data exchange
- ⚛️ **React + Tailwind** frontend with mobile responsiveness
- 🍃 **MongoDB Atlas** for storing student data & scores
- 🖨️ **PDFKit** integration for custom downloadable reports
- 📊 Google Charts used for live graphs
